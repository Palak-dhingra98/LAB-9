This laboratory activity focused on creating, evaluating and improving marketing content for the aviation industry using Generative AI. The main objective was to understand how the same marketing campaign should be adapted for different communication platforms while maintaining factual accuracy, consistency and compliance. The activity used the fictional AeroVista Student Saver campaign, which offered college and university students up to 10% off the base fare on selected domestic routes.

The lab began by identifying the differences between LinkedIn, Instagram, advertisement headlines and promotional emails. Each platform requires a different tone, length, level of detail and communication style. A master marketing prompt was then created with clear information about the target audience, campaign benefits, dates, eligibility requirements, availability restrictions and unsupported claims that AI must avoid.
